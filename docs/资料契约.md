# 电竞直播赞助的去重触达与保量履约资料约定

以下记录全部为本地合成数据，业务名称、参与方及数量不对应真实企业。

日期使用公历，带Z的时间为UTC。缺失值使用JSON null，空列表表示已知集合为空。资料主键仅表示该来源记录身份，业务版本与原始对象字段另行保留。

所有货币为USD美分。家庭触达按合同期唯一家庭计算，分钟为符合条件的可见秒数合计除60。每次合格播放须可见至少30秒，后台播放不合格，监测缺口为未知。
frequency_cap限制一个家庭在整个合同期可用于交付的曝光次数，已达上限家庭不能作为补量的新增合格曝光。触达家庭无论合格次数多少只算一个。
排他广告段只允许归属一个合同，同drink类别广告主即使分别购买权益也不能共占同一个排他段。非排他段只有合同明示允许的不同权益才可并计。
audience_panels中同一panel_household跨场次表示同一调查家庭，未来attended只表示意愿。按场次时间做回测时只能采用该时点已经到达的调查资料，不能把未来意愿当成实绩。
认定账款按合格交付单位乘unit_price_minor，超过保量目标的部分只有另行接受的订单才可开票。账单差额是当前可认定金额与票面金额之差，收款仍单独保存。
recognized_delivery及invoices保存商务当时的外部决定，不声明其符合后续更正后的证据。新证据可以形成差额，不消除实际播放、客户接受或已开票事实。

## devices

匿名观众设备及受众属性。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 设备 |
| region | str | 地区 |
| segment | str | 合成受众层 |
| consent | bool | 是否允许用于赞助计量 |

## household_links

设备联系的证据及生效范围，possible为尚未裁定。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 联系证据 |
| devices | list | 关联设备 |
| household | str | 匿名家庭 |
| status | str | confirmed明确联系或possible可能联系 |
| effective_from | str | 业务生效日 |
| received_on | str | 证据到达日 |

## matches

已发生与未来场次。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 场次 |
| on | str | 直播日 |
| platform | str | 转播平台 |
| region | str | 主市场 |
| competition | str | 赛事季 |
| state | str | 已完成或已排期 |

## ad_breaks

广告段库存，排他性属于整个段。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 广告段 |
| match | str | 场次 |
| start_seconds | int | 距场次开始秒 |
| duration_seconds | int | 广告段长度秒 |
| exclusive | bool | 是否排他交付 |
| inventory_cost_minor | int | 补量采购成本美分 |
| accepted_contract | str / null | 已经承诺的合同，空表示未承诺 |

直接引用关系为match → matches.id。

## sponsorships

赞助合同已接受的业务权益。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 合同 |
| advertiser | str | 广告主 |
| category | str | 竞品类别 |
| metric | str | 保证家庭触达或合格分钟 |
| target | float | 约定保量目标 |
| unit_price_minor | int | 每个合格指标单位的合同美分单价 |
| frequency_cap | int | 每户合同期最多计入曝光次数 |
| regions | list | 允许地区 |
| segments | list | 允许受众层 |
| platforms | list | 有效转播渠道 |
| asset_versions | list | 客户认可素材版本 |
| allow_parallel_credit | bool | 同片段能否并计非排他权益 |
| splittable | bool | 客户可否拆分接受补量 |
| budget_minor | int | 可用于补量采购的预算 |
| period_from | str | 合同期起日 |
| period_to | str | 合同期末日 |

## playback

播放平台原始回传，镜像共享origin_event。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 回传 |
| origin_event | str | 原始播放事件身份 |
| device | str | 设备 |
| match | str | 场次 |
| ad_break | str | 广告段 |
| asset_version | str | 素材版本 |
| visible_seconds | int | 明确可见秒数 |
| played_seconds | int | 播放秒数 |
| covered | bool | 是否有有效可见性监测 |
| background | bool | 是否后台播放 |

## audience_panels

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 调查 |
| match | str | 场次 |
| panel_household | str | 调查家庭身份 |

| segment | str | 受众层 |
| inclusion_probability | float | 纳入概率 |
